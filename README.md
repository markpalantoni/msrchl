# msrchl

Kids video player for a fixed, hand-picked playlist.

Pick a length, pick a video. Plays with no player controls, no
recommendations, and no way out. Near the end it sounds a chime, fades the
audio to silence while the picture fades to black, then stops on a goodbye
card.

The 10 second option is for checking the ending without sitting through a
session.

Entries are inline in `index.html`, all 5 minutes or longer so the timer
always ends the session rather than the clip running out.
